# Security Policy

Security reports concerning the Feelcoin browser wallet are welcome.

Please avoid publicly disclosing a vulnerability before maintainers have had
reasonable time to investigate it.

## Never include secrets in reports

Do not include:

- recovery seeds
- private spend keys
- private view keys
- wallet passwords
- exported wallet vaults
- SSH keys
- API credentials

Public addresses, block heights and transaction hashes may normally be shared
when required for debugging.

## Security status

The Feelcoin browser wallet has undergone functional Feelcoin mainnet testing.

It has not been represented as independently security audited.
